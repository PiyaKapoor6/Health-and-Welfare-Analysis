# Health and Welfare Analysis

A Streamlit-based application analyzing rural–urban healthcare disparities, disease trends, and healthcare infrastructure across Indian states, with a detailed focus on Punjab.

## Key Features

* **India Overview:** Compare healthcare indicators across Indian states.
* **Punjab Analysis:** Explore healthcare statistics and regional health indicators in Punjab.
* **Rural vs. Urban Analysis:** Compare healthcare access and infrastructure in rural and urban areas.
* **Disease Analysis:** Examine disease patterns and potential contributing factors.
* **Trends & Forecasting:** Analyze historical trends and generate forecasts using statistical and machine learning models.
* **Interactive Visualizations:** Present healthcare data through charts and graphs.

## Technologies Used

* Python
* Streamlit
* Pandas
* Matplotlib
* Plotly
* Scikit-learn
* Statsmodels

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/PiyaKapoor6/health-and-welfare-analysis.git
   ```

2. Navigate to the project directory:

   ```bash
   cd health-and-welfare-analysis
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   streamlit run amain.py
   ```

## Objective

To analyze healthcare disparities between rural and urban regions, identify disease trends, and provide data-driven insights into healthcare infrastructure and public health in India.
